## 1. 研究目标与计划的衔接

当前主线是 **iTE 与 TG 两张独立知识图谱之间的 match**：比较概念、单条关系及局部结构的可比性，检验关系与结构信息能否提升匹配质量。

核心对照问题：在相同抽取结果、图谱版本和候选集合下，加入语义角色、方向、已报告条件、概念层级及一跳邻域，是否优于只用名称或关系文本的语义匹配？

原计划第 10 节仍要求首篇工作围绕“证据化双机制图谱＋受控跨图匹配”，域内 mechanism landscape 是独立结果部分。因此，精简的是抽取工程，不是将研究缩减成只有匹配分数，也不删除既定域内分析。

| 原计划 | 本轮落实方式 |
| --- | --- |
| Stage 1：已交付摘要核心陈述 | 保留原始结果；修订、补抽或必要重抽另存版本，不从头重复清洗检索 |
| Stage 2：归一化与质量审计 | 使用本文的精简流程修复已发现问题；保持角色、证据、概念映射与分析范围分离 |
| Stage 3：两张域内机制图谱 | 质量审计通过后构建并冻结；保留支持度、社区、时间和局部 motif 等计划内分析 |
| Stage 4：跨图匹配 | 在冻结图谱、统一候选集上执行四组对照、盲评、消融和敏感性分析 |
| Stage 5：全文与案例验证 | 对 3–5 个正/部分/负案例核查全文及必要 SI；不是全库抽取的前置条件 |

当前抽取不以完整机制还原、完整因果证明、性能排名或科学可迁移性证明为目标。关系匹配成立不等于材料方案可复用；证据有效性、关系匹配、条件兼容与科学可迁移性必须分别评价。

- **抽取流程**：默认完整 Abstract → 一轮结构化抽取 → 一轮集中查漏纠错 → 域内归一化 → 新样本验收。
- **输入范围**：沿用论文作者撰写的 Abstract，不是助手生成的摘要；不默认转为全库全文抽取。
- **旧归一化清单**：按此前用户确认，旧 308＋35 共 343 项合并决定不再是额外待办；不因研究计划保留旧文字而重新启动该队列。新版本实际采用的合并仍须有接受记录。
- **全量处理**：原计划“不自动重跑 1,971 篇”的原则保留。先依据错误分布试行精简修订/重抽，再按验证结果决定扩大范围；本次文档交付没有启动全量任务。
- **额外方法**：逐句覆盖账本、多轮隔离抽取、复杂事件本体及全库全文对照，不再作为默认前置要求。需要增加步骤时先说明实际错误依据，并验证增益。

## 3. 抽取什么

iTE 与 TG 使用同一提示词、字段和粒度规则，按单篇完整摘要分别处理。来源域只表示语料来源，不直接决定物理机制类别。抽取时不提供另一领域的结果、预期 match 或希望出现的机制链。

保存预先界定范围内的全部明确关系，不限定每篇只能抽一两条，不以条数或图连通性为目标。“核心”由范围定义，不按醒目程度只挑结论句。

| 关系范围 | 为匹配提供的信息 |
| --- | --- |
| 材料/设计与相互作用、结构、过程之间的关系 | 调控方式与对象 |
| 相互作用/结构与过程、物理量之间的关系 | 作用关系 |
| 过程/物理量与性能之间的关系 | 作用结果 |
| 条件变化与上述对象或结果之间的关系 | 适用限定与可比性 |

这些是范围说明，不是强制方向或机制链模板；方向、谓词和断言以原文为准。明确的关联、假说、否定、负结果及限制也保留，不统一改成因果。

器件、稳定性、应用等关系继续保留并按 `analysis_scope` 区分。单纯共现、一般背景和没有明确关系的性能数字不混入机制关系集合。本篇结果、综述概括和背景来源按 `article_role`/`claim_scope` 区分。

标题可辅助辨识语境，不替代摘要中缺失的关系证据。没有范围内关系时允许空结果；缺摘要的 6 篇继续保留登记。疑似原文错误标记问题，不依靠常识静默改写。

范围在验收前冻结；不能按“容易匹配”筛边，不能看到低分后删除难例或缩小分母。旧的选择性抽取与本次范围内完整抽取有覆盖差异，比较时必须使用同一参考集和规则。

## 4. 最小记录与粒度

| 字段组 | 内容 |
| --- | --- |
| 来源与版本 | `paper_id`、`domain`、`input_hash`、`extraction_run_id`、`schema_version` |
| 关系端点 | 原文名称、局部 mention ID；保留决定含义的对象和样品身份 |
| 端点角色 | 沿用 `semantic_role`，原 `legacy_role` 保留 |
| 关系 | 主体 ID、原始谓词、客体 ID、方向；规范谓词后续统一，原词不丢失 |
| 断言与限定 | `author_claim`/`association`/`hypothesis`/`negated` 及必要原始措辞；比较对象、联合因素和已报告条件 |
| 联合因素 | `claim_id`、`joint_factor_group` 或共同因素列表 |
| 证据性质 | 实验、计算、理论、混合或未说明；目的性表述不能当成已观察增益 |
| 精确证据 | quote、句 ID、字符区间；需要时包含指代/定义句 |
| 分析与审核 | `analysis_scope`、来源属性、模型接受/需修订/待定状态及简短理由 |

十类角色沿用原计划：`material_entity`、`design_strategy`、`condition`、`interaction`、`mechanism_process`、`state_structure`、`quantity`、`descriptor`、`performance_function`、`application`。不新增平行的分类体系。

未报告的条件留空并标记未报告；原文歧义记待定。不能要求模型填满所有温度、浓度、配方字段。数值单位仅在支持或限定当前关系时保存，本轮不扩展成全面性能数据库。

粒度规则：

1. 原文明说 A 促进 B、B 降低 C，可保存两条边；同篇同一指向的 B 复用 ID，保留真实邻域。
2. 原文只说 A 降低 C，只保存这一条，不补 B；也不由 A→B、B→C 自动添加作者未报告的 A→C。
3. 原文说 A 与 B 共同降低 C，保存共同因素组，不统计为两个独立效应。共同归因不自动证明协同效应或各因素必要性。
4. 多个明确结果可分别保存，但继承共同因素和条件，并关联同一 `claim_id`；参考集和输出用同一粒度计分。
5. 同名但不同样品或物理含义不能盲目复用 ID；同一概念在不同样品中的边仍保留不同语境。
6. 归一化后跨论文拼出的路径不是单篇已报告机制链。真实两边路径须来自同篇，或按明确聚合规则另作标记。
7. 抽取保留具体含义，匹配时再判断抽象对应；不能为了两域更像而把不同电导、熵、输运或热电系数提前混为一体。

初期使用关系表和共同因素字段即可，不要求先开发复杂事件图系统。

## 5. 最小执行流程与提示词

**一轮抽取**：完整阅读单篇摘要，按范围输出最小记录。先不提供旧抽取作为填空模板，也不提供另一领域候选。

**一轮集中查漏纠错**：对照完整原文和初稿，重点检查遗漏关系、联合因素、计算/理论限定、否定/目的性、跨句指代、方向、端点及必要条件。同一轮可以补抽与修正；新增关系也须有证据。未解决项保留待定，不默认开启第三、第四轮。

**域内归一化**：结合本篇定义统一同义概念和谓词；保留原词和证据。已有接受映射仅在对象/语境仍适用时复用；`narrower_than`、`broader_than`、`related_to`、`distinct_from`、`uncertain` 均不折叠。跨域对应另存 alignment，不提前合并两域 ID。

Python 仅做字段、引用位置、ID、重复和哈希校验，语义判断由模型执行。保留新旧差异，检查旧的正确关系是否意外丢失。原始 evidence ID 不重编号，补抽使用新 ID。

抽取提示词基线：

```text
为跨领域知识图谱匹配，从这篇完整论文摘要提取可追溯、可比较的关系片段。
只提取作者明确报告、与材料调控、相互作用、结构、过程、物理量及性能有关的关系。
保存范围内全部明确关系，不限制条数；不由常识补关系，不补齐未陈述的机制链。
器件、稳定性和应用关系按分析范围区分；不把共现、一般背景或孤立数值当作机制关系。

每条关系保存主体、原始谓词、客体、端点角色、必要限定、证据类型、精确引文和论文 ID。
保留共同因素、否定、推测、比较对象及已报告条件；未报告内容留空。
计算、理论与实验来源分别标注，设计目的不自动等于已经观察到的效果。
证据类型 modality 默认 unspecified；摘要未明确说明本条关系的研究方法时不猜。
不得仅凭标题、性能数值、材料制备或“demonstrates”等结果措辞推断实验类型。
只有摘要明确支持本条关系的 experimental/computational/theoretical/mixed 类型时才填写该类型，
同时在 modality_evidence 列表保存对应的逐字原文依据；否则填 unspecified 和空列表。
mixed 要求本条关系确有多类方法支持，不能把整篇方法标签复制给每条关系；
引用文献实验对模型的验证，也不自动使每条计算预测成为 mixed。
证据类型未说明不影响保留原文明说的关系，不因此删边或省略计算、理论关系。

同篇同一对象复用局部 ID；不同对象/样品语境不得仅因名称相近合并。
多个结果可分别记录，但保留共享因素和条件。没有明确关系允许空结果，歧义保留待定。
```

复核提示：对照完整摘要与初稿，补回有明确证据的遗漏，修正方向、指代、联合因素、模态和条件；输出修订结果与简短差异，不要求每篇建立长篇逐句账本。

首轮新输出在进入复核或归一化前，必须执行轻量校验：
`python3 stage2_normalization/modality_guard.py input_papers.json raw_records.json output.json`。
输入沿用论文数组（原文含 `paper_id/abstract`，抽取含 `paper_id/records`）；新增字段仅为每条关系的 `modality_evidence` 引文列表。
脚本补齐默认值；缺少依据或引文不在本篇摘要的类型退回 `unspecified`，原提议及原因另存 `output.json.audit.json`，关系和其他限定不改动。字段格式错误直接报错，不覆盖既有输出。
该校验只验证来源定位，不判定引文是否真正支持该关系的证据类型，也不替代其他字段校验或 Astra 抽样。仅用于按新提示词生成的输出，不批量套用缺少新字段的历史记录；冻结试验及其脚本保持不变。当前没有自动调用模型的批量后端，此命令是新抽取的必经本地步骤。

## 6. Stage 2 验收及 Stage 3 图谱输出

开发用已检查案例，验收用未参与本轮修改的新样本。参考集按冻结范围先从原文建立，再对照输出；Astra 参考如实标记为模型参考。当前已修过的 200 条/60 篇样本不能再冒充新的独立验收。

沿用计划的审计结构：每域 100 条关系检查精确率、每域 30 篇摘要检查范围内核心召回、约 50 条挑战案例单独回归。样本不等概率时采用设计权重；报告分子分母与按论文聚类的不确定性。挑战分数不混成总体精度，阶段性抽样分数不等于总体保证。

两域严格精确率目标约 90%、核心召回约 70%，引文定位全部通过；高影响合并有接受记录。部分覆盖单列，必要限定缺失不算完整正确。新旧方法在同一范围与参考集下重计，不能直接与旧口径百分比比较。

先在小规模检查“一轮抽取”与“加一次复核”的质量和开销；不为展示提升增加无依据关系。未达标优先处理错误集中的类型/批次，是否扩大重读范围由实际证据决定。

按计划保留证据、概念、分析三层数据，不意味着必须建设三个新系统。主图纳入 `intrinsic_material_mechanism`、`thermodynamics`、`ion_mass_transport`、`electrode_interface_kinetics`，最后一类与体相区分；其他既有范围标签作为外围/方法层，语料不因此整篇删除。

通过验收后，分别生成并冻结 iTE/TG 图谱，记录规范化版本。边权以独立支持论文数为主，mention 数辅助；保留断言分布和证据链接。计划内结果包括：

- 两域 GraphML/JSON 和图谱总览。
- `domain_concept_stats.csv`、`domain_relation_stats.csv`。
- `community_assignments.csv`、`temporal_stats.csv`、`motif_stats.csv` 与域内 landscape 报告。
- 通用 hub 保留/移除的敏感性；足够年份才使用三年滚动；两边 motif 的同篇或聚合依据。

这些是原计划后续交付，不是重抽前要先完成的条件。域内证据稀疏不称为科学空白，高支持度或中心性不解释成机制更重要。

## 7. Stage 4 匹配实验保持不变

Stage 2 质量通过、Stage 3 两图冻结后，再生成跨域候选。基本单位先是 `A—r→B` 对 `C—s→D`，再扩展两条边的局部结构。

候选采用精确/别名通道与关系文本语义通道；语义通道按计划双向 Top-20 合并去重，开发期可比较 Top-10/20/50 后冻结。未进入候选集合不等于负例，双向检索不等于双向物理迁移。

四组方法使用同一冻结图谱和候选集合：

1. Exact：规范名称、别名及谓词精确对应。
2. Semantic：端点与整条关系文本语义。
3. Relation-constrained：加入角色、方向、已报告条件及概念层级。
4. Neighborhood-enhanced：进一步加入一跳邻域。

保留主体对主体、客体对客体的方向；条件缺失为 unknown，不当作兼容或冲突，按计划从该候选有效评分分母排除。权重只在开发集的小范围组合中选择后冻结，不宣称物理意义。

沿用评价设计：约 60 个开发候选；四方法各 Top-50 合并去重、打乱、隐藏方法及分数后评价；约 50 个困难诊断候选单列。Astra 按顺序判定双方原文证据是否成立、关系匹配 2/1/0、条件 compatible/conflict/insufficient。主要报告 P@20/P@50；严格正例要求双方证据成立且关系匹配为 2。

不把未标注候选设为负例，不报告无全空间参考集支持的全空间召回率。保留方向、条件、层级、邻域消融，通用 hub 与计划登记的 66 篇历史跨集合重复论文、综述、混合及相邻领域敏感性分析；不自动删去默认语料。

不能根据最终匹配成绩反改抽取、选边或补邻域。如果结构没有稳定优于语义基线，照实报告，不为正结果增加复杂模型。

## 8. Stage 5 和当前暂不扩展的工作

按原计划选择 3–5 个跨机制族案例，覆盖高置信、部分/条件不足和失败/冲突。必要时核查正文及 SI，补充条件、对照、测量方式和替代解释，再讨论物理可比性及科学启发。新颖性需另查文献/专利，不能由当前图中缺边推出。

不把全库全文抽取、完整因果证明、数值性能数据库、多轮独立抽取、复杂事件本体、两跳以上学习式对齐、GNN 或实验验证设为当前抽取前置条件。额外步骤只在实际错误与对照结果支持时加入。
