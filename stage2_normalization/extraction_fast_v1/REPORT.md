## 本次节省与真实边界

单批读取 8 篇完整摘要；未启动抽取/参考/裁判多套代理，没有独立参考标注和全量盲评。作者化记录共用证据片段，程序展开引文、赋记录 ID、检查来源并冻结文件；复核只写增量。没有为减少输出设关系条数上限。

从输入冻结到首轮校验约 250 秒（4 分 10 秒），期间交错处理用户研究问题和检索，不能作为纯抽取吞吐基准。原文摘要共 11,833 字符，作者化序列化脚本 15,435 字符，程序展开的首轮 JSON 51,172 字符。字符不是 token；没有本次精确 token 用量，不声称 token 节省百分比，也不按此线性推算全库耗时。

**流程已做轻量化试跑，但尚不是完成的全量自动后端。** author.py 仅重放 Astra 已写好的判断，不能抽取新论文；modality_guard.py 可校验不同输入批次。当前没有自动模型调度、断点续跑与全库吞吐验证。此次没有全量启动、付费 API 或旧监听。

## 与探索性研究目标的关系

用户明确目标是探索两领域 match 是否能带来 insight，并非必须完成材料效果验证。候选 insight 可先基于可追溯的局部关系探索；基础证据与明显物理冲突需核查，实验或计算验证不作为提出候选的前置门槛。未证实新颖性时不声称全新发现，未验证效果时不声称迁移有效。此次仅抽取，不执行匹配。
