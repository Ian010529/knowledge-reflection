# Embedding 输入对比试验

本次仅完成开发诊断。推荐保留“名称＋节点所在原文短句”作为下一步候选方案；证据尚不足以宣布它全面优于原方案。未覆盖正式候选，未改研究计划、历史决定或人工栏，未合并节点、建图或恢复旧逐对模型任务。

## 方法与样本

固定本地 Nomic v1.5、revision e9b6763023c676ca8431644204f50c2b100d9aab、clustering 前缀、768维、同域 Top-10、同论文可检索、排除自身。三个方案均在完整的4,487个可用节点中检索，不在小样本内部检索。159个角色待核实节点沿用原方案单列，不纳入本次实验。

比较原80词窗口、节点名称＋所在原文句子/分号分句、仅节点名称。短句规则是按标点切分后选取包含首次名称的片段，不调用模型改写，不按逗号拆开，也不保证已解析所有指代。4,481项使用短句，6项因片段超过80词回退到原窗口。平均上下文长度从51.03词降为27.89词。所有片段均校验为原文连续子串并保留节点名称。

抽样在新输入检索结果计算前固定：每个域，从历史 distinct 和 related 建议中各取6对；从同标签 equivalent 和异标签 equivalent 建议中各取3对。按 SHA256('context-trial-v1:' + comparison_id) 排序选取，共36对，另加已知难例N0838。来源是历史队列，样本并非全语料随机样本，也不是独立测试集。

本次助手逐项阅读两侧完整quote，记录12对等价、21对非等价、3对待定；另一个挑战对为非等价。判断是模型原文复核，不是人工金标准或专家验收。具体边界与理由见review_notes.json；与历史建议不同的判断只用于本次诊断，不写回主表。评分时已知分层依据和既有挑战，不能称完全盲评。

## 结果

“找到”表示具体节点对任一方向进入同域Top-10，不等于合并，也不代表同一名称的每次出现都必须互相进入Top-10。

| 输入 | 12对本次复核等价样本中找到 | 21对非等价样本中也进入候选 | 历史501对等价建议中找到 |
|---|---:|---:|---:|
| 名称＋原80词窗口 | 6 | 5 | 211 |
| 名称＋所在原文短句 | 8 | 7 | 267 |
| 仅名称 | 12 | 16 | 436 |

3对待定样本在三种方案中均进入候选。挑战对不混入上述分层统计。

短句相对基线新增找回N1223、N0656、N0331，丢失N0645（其最佳方向由第10变为第11），净增加2对。说明收益不均匀，也存在Top-10边界效应。仅名称覆盖最高，但无法区分不同对象下的同名指标，例如压力灵敏度和温度检测灵敏度被赋予相同输入。

N0838负/正Seebeck系数：原窗口相似度0.992679，互为第1；短句0.8654，两个方向为第17/57；仅名称0.9370，第67/73。短句改善了这个已知共享段落难例，但不能由单例推断总体效果。

仍未解决的例子：N0730中Fmoc-FF材料与Fmoc基团间π相互作用在同一句内，短句方案仍为约0.9818并互为第1。N0102的Cr掺杂短句还可能省去宿主材料或替位信息。因此完整quote必须继续作为复核证据保留，embedding分数不能判定同义。

## 如何解读与下一步

- 非等价候选包含相关、上下位、属性与过程等关系，进入检索候选本身不是错误；本表不能计算总体准确率或误合并率，也未穷尽标注所有Top-10邻居的相关性。
- 历史501对是模型建议；精确节点对覆盖不是人工金标准召回率。同标签重复出现还会占用近邻名额，不能从436/501推导正式召回率。
- 小样本支持把短句方案作为下一步开发候选，不能证明全面优于基线；仅名称作为对照保留，不直接替换计划规定的“名称＋简短上下文”。
- 暂不增加K、不换模型、不调0.95合并阈值、不扩大为全候选逐对大模型调用。进一步采用短句前，需在计划的归一化人工复核中核实收益和遗漏，尤其检查对象、符号、方向及上下文依赖。
- 本次没有改写正式候选或计划。下一阶段的模型建议仍不能代替343项既有合并决定及新增高频合并候选的人工验收；本试验也未核实/重建那343项复核表。

## 运行与校验

首次试验共138.89秒：短句编码95.84秒、仅名称编码40.06秒，原向量复用缓存。两个新方案均在本机运行，没有外部生成式模型API调用；助手阅读原文、写脚本和分析仍使用本对话token，不能声称整个实验零token。

独立使用einsum复算37对×3方案的相似度及双向排名（浮点并列容差2e-6），核对基线样本Top-10与原输出一致；正式候选及历史文件哈希未变化。详见independent_validation.json和summary.json。

复现（保留本目录冻结样本及review_notes.json）：

```bash
.venv-embedding/bin/python stage2_normalization/compare_embedding_inputs.py
```

脚本只写本实验目录。已有向量缓存按完整输入、模型revision和编码参数指纹复用。

sample.json为冻结样本和两侧原文；review_notes.json为模型复核及理由；focused_inputs.csv为全部短句和来源位置；pair_results.csv为111条样本/方案结果；sample_top10.csv为样本节点的近邻明细；summary.json为参数、统计、耗时和来源哈希。
