## 实际执行

941 个候选组、3,575 个节点分为 64 批，Astra-medium、ChatGPT 登录 Codex CLI、4 路并发，一轮判断。候选只来自同名/大小写变体及同篇字面括号形式，不读 RRF 候选表。大小写相似不直接触发合并。余下节点按原词保留独立映射，不冒充已经做过语义归一化。

4 个括号候选实际为不同组成的并列材料（Ba3SiO/Ba3GeO、LiMgN/LiZnN、Ba2ZrS4/Ba2HfS4、Ti2MnB/Zr2MnB），均保持分开。本轮没有由这些候选获得新的缩写合并。冻结提示词将此候选来源称为 definitions，措辞过强；已在协议记录，未改写原输入、提示或回复。

每个概念保留原始别名、成员节点、模型判断与原因；每条关系作为独立有向多重图边，原谓词、端点原词、条件、联合因素、模态、断言、引文、论文来源和审核状态均保留。方向表示原始主客体方向，不等于因果已证实。未额外统一谓词、创建上下位边或抽象机制链。支持文献数按 DOI 去重，无 DOI 时按论文 ID 计数，不能视为独立实验次数。

## 核验

[程序核验](verification.json)通过：941 个组判断完整，每个组成员及全部 27,065 个局部节点恰好映射一次；所有原始关系字段原样保留；20,984 条入图关系与 131 条待定关系完整闭合；39,508 处引文/方法位置与原文一致；无跨域合并和悬空端点；两个 GraphML 解析成功，节点/边数及完整边字段与 JSON 一致。输入哈希未改变。

额外检查了成员重复、遗漏和未知 ID 的拒绝规则；浏览器中验证领域切换、概念搜索、核心范围过滤和原文展开，未出现 JavaScript 错误。TG 唯一自环为原始 P0040:r002 的 is_edible 属性表达，其原始主体与客体 ID 已相同，并非本轮合并制造；保留原记录，不在本轮重抽修正。

## 成本

64 次模型调用均一次成功，无重试。首个模型调用开始到最后完成 **17.05 分钟**（含首批检查间隔），平均每批 58.1 秒；不含此前程序准备、后续导出和页面验证。

- 输入 1,538,971 tokens，其中缓存输入 266,240。
- 输出 105,572 tokens，其中推理输出 10,525。
- 合计 1,644,543 tokens；缓存与推理已包含在输入/输出内，不重复累加。

实际用量高于最初估计，首 4 批后已向用户修正。账户周额度在任务前估算时剩余 51%，模型完成后剩余 43%；这是账户共享额度观察，包含本会话和可能的其他任务，不是隔离计费测量。未使用付费 API 或额度重置。

## 质量边界与后续

本版完成的是用户授权的最小归一化与初版建图，不是完整别名消歧或总体语义验收通过。未为归一化另建独立金标准，也未重新测量修订抽取的总体准确率。模型注释和定义不是新增原文科学主张。

模型较保守，例如将部分同一物理量按计算/测量语境保留为不同节点；这种区分不必然代表物理概念不同，属于可能漏合并的限制。未根据这一现象自动追加第二轮全库复核。不同叫法和带材料/数值限定的单例仍可能分散，不能从图谱缺边或无 match 推断科学上没有联系。

全范围图的弱连通分量为 iTE 4,347、TG 939，最大分量分别为 5,452、203 个节点。这是当前表示下的描述，不能据此评价领域是否成熟、是否存在科学空白或能否跨域迁移。正式域内 landscape、对照匹配及案例分析尚未执行。
