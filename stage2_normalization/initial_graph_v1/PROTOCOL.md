- 候选只按域内 NFC/空白规范化后的同名与大小写变体，以及同篇完整摘要中的字面括号邻接形式形成。大小写比较仅用于找候选，化学式等是否等价仍需模型判断。

- Astra-medium，ChatGPT 登录的既有 Codex CLI，4 路并发；工具禁用，只读取提供的证据和关系上下文。每组一次判断，按规范概念划分，歧义项单独保留；没有第二轮独立语义验收。技术失败最多重试一次；授权/额度失败停发新批次，不使用付费 API 或新的额度重置。
- 节点合并不合并具体主张。每条原始关系仍是独立图边，保留方向、谓词、材料端点原词、条件、数值、联合因素、断言、模态、原文及审核状态。图边有方向不代表因果已证实。
- 单例不因无候选而被认定语义正确；待定、未审和已判断状态明确区分。模型定义是归一化注释，不是新的原文科学主张。
