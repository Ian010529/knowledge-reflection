# 关键词＋向量相似性检索试验

已完成本地方法对照，未安装Elasticsearch，未重算embedding，未调用新的生成式模型或改写正式候选、历史判定和人工栏。没有合并节点或建图。

结果：关键词通道明显补足了当前短句向量检索对既有比较的遗漏；本次证据不足以认定融合全面优于纯关键词，也不足以替代概念等价复核。

## 固定设置

- 4,487个可用初始节点，iTE/TG分别检索，排除自身，允许同论文。未合并初始节点不是最终概念数。
- BM25：查询与文档均为节点名称；k1=1.2，b=0.75；每个域分别计算文档频率与平均名称长度。idf=log(1+(N-df+0.5)/(df+0.5))。
- 分词：Unicode字母数字、大小写折叠、标点切分；保留n/p、否定词和常见词，不做词干化、同义词扩展或化学式解析。查询词去重。只返回正BM25分数项，不用零分项填充。
- 向量：复用上一轮“名称＋原文短句”的Nomic v1.5向量；模型revision及输入指纹见summary.json。
- 融合：两个通道分别取Top-10，以等权RRF、常数60融合，再取最终Top-10；相同分数按mention ID排序。不使用语义标签、角色、历史决定或样本判断参与排名，不据样本调参。
- 这是Python实现的BM25/RRF方法实验，不是Elasticsearch部署测试，也不宣称与其分词器、字段长度压缩和分片统计逐位一致。

参数依据：[Elasticsearch BM25默认设置](https://www.elastic.co/docs/reference/elasticsearch/index-settings/similarity)、[Lucene BM25 IDF](https://lucene.apache.org/core/9_12_1/core/org/apache/lucene/search/similarities/BM25Similarity.html)、[RRF排名融合](https://www.elastic.co/docs/reference/elasticsearch/rest-apis/reciprocal-rank-fusion)。

## 对照结果

沿用上一轮冻结的36对分层诊断样本及1对已知挑战，不重新选择样本。助手原文复核的36对中，12对等价、21对非等价、3对待定。这些不是人工金标准，且同一开发样本已用于多次实验，不是独立测试集。

| 方法 | 12对等价样本中找到 | 21对非等价样本也进入候选 | 历史501对等价建议中找到 |
|---|---:|---:|---:|
| 纯短句向量 | 8 | 7 | 267 |
| 纯BM25关键词 | 12 | 15 | 469 |
| BM25＋短句向量RRF | 12 | 14 | 467 |

找到的定义为该具体节点对任一方向进入同域Top-10。3对待定在三种方法中均命中，正负Seebeck系数挑战在三种方法中均未进入Top-10。

相比纯向量，混合检索补回4对本次复核等价样本：thermodiffusion effect/thermodiffusion、thermovoltage/thermovoltage signals、两种PEDOT域间距增大的表达、两种PEDOT:PSS电导率的表达。同时也新增召回电流密度/电流、浓度梯度/浓度、n型/p型等非等价候选。检索覆盖改善没有消除语义区分任务。

与此前两路向量融合相比，本次小样本汇总数字同为12对等价、14对非等价进入候选，不能从这组样本声称关键词混合更准确。

历史模型等价建议具有明显名称重复：302对大小写折叠后名称相同，199对不同。纯BM25分别覆盖302/302、167/199；融合为302/302、165/199；纯短句向量为150/302、117/199。这些覆盖不是人工金标准召回率。融合相对BM25补回8对，同时挤出10对，合计减少2对；ID明细见independent_validation.json。

## 候选量及成本

- 全部节点检索后的无向候选对：BM25为28,601；短句向量34,721；混合32,679。
- BM25有504个节点不足10个正分匹配；另两种方法每个节点恰好10个候选。故不能把BM25较少的候选对直接解释成等预算下更高精度。
- 上述只统计各检索方法，不含历史、结构等渠道的最终并集，不能直接拿32,679与正式49,999候选池比较或声称已减少模型工作量。
- 运行约2.95秒，额外独立校验约5秒。没有新embedding或外部生成式模型调用；本对话分析和代码编写仍使用token。

## 判断与下一步

关键词通道值得保留作为候选召回的对照，且无需迁移Elasticsearch便可验证。当前小样本没有证明融合比纯关键词全面更优，因此不自动覆盖正式流程，也不继续围绕这36对调权重。

后续应将这两种候选方案与原方案一同放入计划要求的归一化复核，观察有效同义覆盖和实际复核负担，核实对象、方向及适用域，再固定正式实现。不能以检索高分或历史模型等价建议直接合并。此次仅完成用户要求的检索试验，未启动任何后续模型逐对任务。

## 校验及复现

74个样本节点的BM25对同域全部文档逐项用独立标量公式复算，最大分差0；向量通道样本排名与上一轮完全一致；全部4,487个查询的RRF Top-10独立重建一致。所有方法无自身、重复、跨域邻居；来源及正式文件哈希未变化。

```bash
.venv-embedding/bin/python stage2_normalization/compare_keyword_semantic.py
```

`summary.json`记录参数、来源哈希和统计；`pair_results.csv`为37对×3方法的诊断结果；`historical_coverage.csv`为全部1,692对历史比较的覆盖；`sample_top10.csv`提供样本节点的候选名称和分数；`all_top10.npz`保存全量邻居索引（-1表示无正分BM25候选，以mention_ids为索引表）；`independent_validation.json`为独立复算及名称分层统计。
