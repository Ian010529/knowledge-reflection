## 执行与消耗

全程使用 ChatGPT 登录的 Codex CLI 调用 **gpt-6-astra、medium**。每批最多 12 篇完整作者摘要，固定提示与 schema，一轮模型输出并在输出前自检；程序定位原文、运行证据类型 guard、检查字段和保存检查点。没有给每篇重复建立独立参考或另开盲评，没有切换 Sol。并发由初期单路/3 路提高到 **6 路**；12 路仅做可行性评估，未实际测试。

首个成功请求开始至最后完成约 **188.8 分钟**，包含并发切换和运行间隔；不包含更早的准备与首次直连失败。成功批次平均 371.4 秒。不同批次长度和输出量不同，不能据此作严格并发因果比较。

CLI 成功调用计量：输入 **2,991,459 tokens**（其中缓存输入 1,049,600），输出 **1,989,370 tokens**。缓存输入是输入的子集；推理输出 20,347 为输出的子集，不重复相加。计量不含当前主会话、历史试验或失败调用，不能等同于 API 费用。按用户明确授权已使用 **1 次现有额度重置**，记录见 reset_authorization.json。

首次直连路由失败后使用本机已有系统代理，原失败日志保留；后续 165 个批次均成功，没有未解决的失败批次。没有重跑已成功批次，没有使用付费 API、旧 dsh 或监听。
