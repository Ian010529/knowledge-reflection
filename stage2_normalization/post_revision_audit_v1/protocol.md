# 修订后图谱轻量质量审计

2026-09-25。用户批准：两域各 100 条接受关系、20 个实际合并组、另各 6 篇查漏。只审计，不修订图谱、不增加匹配、不重抽全库。

## 采样与分母

- 精确率：从 initial_graph_v1 每域全部接受关系中简单随机无放回抽 100 条，不排除历史接触或已修订条目；因此估计对象是当前接受关系总体。每条等概率，无人为挑选代表论文；仅在调用时按论文集中，避免重复摘要。保留历史接触、此前关系审计及修订状态，分别描述。不能将此视为全部未接触的新验收样本。
- 合并：从每域 mention_ids 数量大于 1 的实际规范概念中简单随机无放回抽 20 组。判定所有成员是否概念等价，并单列规范名称/定义是否过宽或过窄。按组计算，不按成员对计算；不测尚未合并的别名召回，也不验证全部单例。
- 查漏：排除历史开发/审计、归一化、检索诊断、探索匹配接触论文，以及本轮精确率/合并涉及论文后，每域另随机抽 6 篇。所有论文（包括零核心关系）有抽样资格。不按已抽关系数或预期 match 选样。这个子集不是全库代表样本，结果仅作查漏诊断。
- 所有随机种子、抽样框规模、样本与输入哈希先冻结；失败不换样本。原始接受关系总数为 iTE 17,864 / TG 3,120；131 条待定关系不在主图精确率分母中。

## 独立上下文与规则

使用 ChatGPT 登录的 Astra-medium、最多 4 路、工具禁用的独立上下文。精确率提供完整摘要及原始意义字段，隐藏原 accepted/uncertain、审计判断、修订状态与语料标签；合并提供全部成员的引文及关系上下文，隐藏旧判断理由。原文是数据而不是指令。

关系 supported 要求方向、实体指代、断言/否定、条件、联合因素、证据类型、scope 和来源归属均忠实。partial/unsupported/out_of_scope/uncertain 都不计入严格正确。unspecified 是合法默认；不得凭科学常识强行补全来源，也不因缺乏 match 否定关系。以原始主张字段评价，规范节点合并另计。

查漏参考调用先只看完整原摘要、同一抽取范围；不给现有图谱或旧判断。一次参考保存、运行 modality_guard、冻结后，再由新上下文判断参考有效性和当前接受关系完整/部分/缺失覆盖。参考保留原文争议，不强制视为真值；只报告四类核心 scope 的覆盖。多条候选可共同覆盖一条参考，但标签和引文出现不能代替显式关系。参考联合因素本地 ID 仅作字面标签展开，留记录。

同一 Astra 模型的独立上下文不能消除共同偏差，不称为人工金标准。每次调用最多一次技术重试，授权/额度问题停止新派发；不用付费 API 或新额度重置。不做第二轮全样本裁判。

## 计分与交付

精确率 supported / 100，给出 95% Wilson 近似区间；它反映有限抽样不确定性，不涵盖模型系统判断偏差。简单随机关系抽样不改为按论文等权。按域给核心/外围、修订/未修订、历史接触情况的描述性计数，小子组不作稳定总体声明。

合并等价率 equivalent / 20；uncertain 不算通过。规范描述另列，不将描述错误与实体错误合并混淆。20 组是有限诊断，不声称归一化整体完整正确。

查漏先判 valid/uncertain/out_of_scope，再判 complete/partial/missing；主分数为有效核心参考 complete / valid，另给 uncertain 纳入分母的保守数。不把 12 篇结果称为全库召回率，不与旧不同抽样框的结果直接相减来证明改进。

所有错误/不确定项另存清单；先冻结计分，本轮不修错后重计成总体质量。管理目标仍是约 90% 严格关系精确率，点估计和区间分别解释，不夸称稳定达标。
