# 同域 embedding 候选生成结果

本轮完成本地向量计算、同域 Top-10 检索、多通道候选合并，以及历史判断关联。没有调用生成式大模型，没有修改原始数据、已有判定或人工栏，没有合并节点或建图。这是研究方案 Stage 2 的候选生成产物，不是归一化验收结果。

## 范围与方法

- 使用 4,487 个可用初始概念：iTE 3,517、TG 970。它们仍是一节点一概念的未合并占位概念，不能当作最终独立机制数。
- 159 个角色待核实节点单列在 `role_deferred.csv`。覆盖范围比旧候选涉及的 4,105 个节点增加 382 个。
- 输入为原始概念标签和围绕短语截取的至多 80 个连续原文词。4,487 项均找到短语，不存在缺词回退；完整 quote、截取位置、节点与概念 ID 均保留。
- 本地模型为 `nomic-ai/nomic-embed-text-v1.5`，revision 固定在 `summary.json`。使用 `clustering:` 前缀、768 维归一化向量、MPS、每批 4 条、2 个 CPU 线程和 0.35 的 MPS 内存分配比例上限。
- iTE、TG 分开检索；每个初始概念选取同域其他概念的 Top-10，可包含同论文候选，不跨域、不与自身配对，不用 0.95 阈值决定去留或合并。
- 首次向量计算约 139 秒，整个首次运行约 143 秒。随后只使用缓存修正浮点边界与生成报告；summary 中的运行耗时若 cache_reused=true，表示缓存读取及后处理，不是重新编码耗时。

## 合并及历史复用规则

语义候选去掉反向重复后为 34,532 对。再合并旧字面/结构渠道的具体代表对、同标签组的锚点对及全部历史比较，形成 49,999 对。旧结构渠道仍使用其原有 legacy-role 邻域签名；本轮没有将其声称为新语义角色下重新计算的结构候选。

旧字面/结构候选原本是检索组对，因此只沿用各侧首个可用成员作为代表，不展开笛卡尔积。组内其他成员及覆盖范围可由原始成员表和 candidate_groups.csv 追溯。具体节点对上的结果绝不传播给整组。

1,692 对历史判断全部保留并关联：

- 1,357 对关联为可复用的模型建议，仍待人工验收。
- 295 对已有 uncertain 建议，保留在待复核队列。
- 40 对涉及最后一批未发布复核或其连通冲突，保留在待复核队列；没有自动采用冲突批次的新结论。
- 48,307 对没有已有的正式主表判断。

候选采用稳定的节点 ID 排序。历史左/右方向、原关系和原理由独立保存；当方向相反时，只在 historical_relation_aligned 字段转换 broader/narrower，不改写原理由。历史建议不是人工金标准。

## 方法诊断与限制

历史 501 对 equivalent 模型建议中，任一方向进入 Top-10 的有 211 对，Top-20 为 273 对，Top-50 为 349 对。这只是既有模型建议的检索覆盖诊断，不能称为人工金标准召回率；本轮最终输出依然是计划要求的 Top-10，并通过历史渠道保留全部已有比较。

候选池中 3,265 对相似度超过 0.95，其中 3,238 对来自同一篇论文。例：N0838 的“negative Seebeck coefficient / positive Seebeck coefficient”使用了同一段同时讨论正负系数的原文，分数约 0.992679，原有判断为 distinct_from。这说明共同上下文可能盖过节点本身的区别，0.95 不能直接当作同义合并阈值。

候选池相较旧队列扩大，不能据此声称大模型工作量已经减少，也不能认定当前 Top-10 覆盖充分。进入大模型辅助复核前，需要先检查输入与检索质量、确定重点审核范围；模型复核不能冒充计划要求的人工验收。没有自动恢复旧逐对调用流程。

## 复现

在项目根目录运行：

```bash
.venv-embedding/bin/python stage2_normalization/generate_semantic_candidates.py
```

模型使用本地已缓存权重；命中输入指纹时复用向量。重新生成只覆盖本候选输出目录中的派生产物，不写回历史判断表。
