The reference author read only the delegated task, protocol.md, schema.md, inputs/reference_all.json, materialize.py and its own work/reference directory. No extraction candidates, other role output directories, old results, metrics, network calls, external APIs or additional agents were accessed. The materialize.py validator was invoked as authorized and internally resolves the same input corpus for IDs, hashes and quote verification.

All 60 papers were authored once in six source-only batches, in supplied order. Python only serialized authored semantic judgments, assigned local IDs, checked input coverage and exact quotations, and materialized/froze the reference. There was no candidate-aware revision. The freeze is protocol isolation, not an operating-system access barrier. This is a same-model independent-context reference, not a claim of independent human ground truth or semantic accuracy.
