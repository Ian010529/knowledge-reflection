# iTE/TG 摘要关系重抽设计 v1

> 历史设计，已由结合研究计划和用户后续澄清的 [跨领域 match 执行约定](../CROSS_DOMAIN_MATCH_EXTRACTION.md) 替代。本文中的逐句覆盖账本、多轮隔离复核、完整主张分层及三版本试验不再是默认要求。仅供方法来源和设计历史追溯，不据此启动任务。

日期：2026-09-24。状态：方案已设计，尚未启动新一轮重抽或验证。

## 1. 目标与证据边界

目标是在冻结的摘要中，完整保存预先界定范围内、作者明确报告的机制相关主张，包括负结果、限制、计算预测与解释性假说。抽取单位是“带上下文和证据的主张”，随后生成图谱关系。

这套组合流程是针对本项目的设计；下列研究为其中的组件提供依据，并未验证整套流程在 iTE/TG 上一定有效。是否采用全量重抽，由本地对照试验决定。

用户已指定由 Astra 替代人工抽检。本方案沿用该安排，明确标注模型参考集与模型验收，不称为人工金标准，也不把同一模型的重复判断当作独立证据。Python 只做格式、溯源、计数和匹配结果记账，不能替代语义判定。

保留原始 1,977 篇登记、1,971 篇有摘要记录和 6 篇缺摘要状态。旧抽取、旧判断、原始引文及哈希不改写；不自动启动全量任务、旧 dsh 任务、付费 API 或监听。

## 2. 为什么采用这些设计

本轮修订前，200 条关系中 163 条直接支持、37 条需要限定；其中 20 条有联合因素问题、10 条有计算模态问题，两类重叠 1 条。60 篇摘要的 143 条参考关系中，39 条完整、23 条部分、81 条未覆盖。原始输出声明为非穷尽核心陈述，因而必须先统一“核心”范围和计分单位，再比较新旧方法。

| 方法依据 | 已发表研究支持的做法 | 本项目的使用方式及限制 |
| --- | --- | --- |
| Dagdelen 等，Nature Communications 2024 | 材料信息可用层次化结构保存复杂实体关系；严格匹配与语义评价分别报告 | 用主张记录保留材料身份、结果和限定。其模型采用微调，不能据此声称我们的提示词流程具有同样效果 |
| SciREX，ACL 2020 | 文档级指代及多元关系；部分多元关系不能无损拆成独立二元关系 | 保留联合因素组，读取完整摘要；不照搬该文机器学习任务中的实体类型 |
| Huang 等，ACL 2022；Re-DocRED，EMNLP 2022 | 只在已有推荐关系上修订可能漏标；从原文重新标注可发现遗漏 | 覆盖核查先形成自己的原文主张清单，再看抽取结果；这不能保证同模型核查完全独立 |
| Eider，Findings ACL 2022 | 结合局部证据和完整文档上下文，在关系抽取基准上得到改进 | 保存支撑片段同时保留整段摘要；只借鉴证据与上下文并用，不声称复现其训练模型 |
| EDC，EMNLP 2024 | 分离开放抽取、定义和后续规范化 | 提取原词与上下文后再规范概念；沿用本项目角色定义，不临时自由重建整套本体 |
| INDRA，Molecular Systems Biology 2023 | 保存机制陈述及证据，分析错误并筛选可靠记录，考虑系统性错误 | 证据记录与分析图分层；未经校准的模型自报置信度不作为入图门槛 |

## 3. 冻结抽取范围

“核心”指符合下列定义的、与论文研究对象直接相关的明确主张，不指每篇只挑最重要的一两句。不设置每篇关系数上限，不按图的稀疏程度补关系。

### 主机制集合

保存摘要明确陈述的以下关系，无论正向、负向、无明显变化还是条件性成立：

- 材料组成、改性或结构与相互作用、状态、过程之间的关系。
- 相互作用、过程、状态与物理量或目标性能之间的关系。
- 温度、浓度等工况变化与上述对象或结果之间的关系。
- 文中明确给出的热力学、离子或质量输运、电极界面动力学关系。
- 明确的经验关联、计算预测与作者机制解释，分别标注证据性质与断言强度。

不要求每条主张都形成“材料—相互作用—过程—物理量—性能”的完整链；某一步没有原文证据就留空。文中仅报告 A→C 时，不生成 A→B→C；报告 A→B 与 B→C 时，也不另把 A→C 算作作者直接报告的关系。

### 扩展集合

器件热管理、机械与环境稳定性、应用传感、测量方法、模型描述和相邻领域关系继续保存，按主张标记 analysis_scope，与主机制集合分别评价。混合论文可以同时包含主机制与扩展主张，不整篇删去或硬归一类。

一般背景、研究动机、仅共同出现的实体、没有关系的性能数字不算核心关系。综述概括保留来源属性，但不当作新增独立实验支持。单独的数值不在本轮扩展为全面性能数据库；若数值、单位、比较基准决定当前主张的含义，则必须随主张保留。

原文歧义、不明确指代和疑似化学或单位错误标记 unresolved/source_inconsistency；不根据常识改写作者原文。撤稿与疑似重复文献保留登记，但对分析资格及独立论文计数单独处理。

### 范围版本

该定义是在旧的选择性核心抽取基础上进行操作化和覆盖扩充。旧的 17.8%/40.6% 召回率仅保留为历史基线；新旧方法必须在同一新参考集、同一主张单位下重新计分，不能直接跨口径宣称提升。

## 4. 保存主张，再生成边

每条主张至少包含以下信息；只有原文支持的值才填入，未报告与尚不能判断分别记录。

| 字段组 | 内容 |
| --- | --- |
| 溯源 | domain、paper_id、abstract_hash、run_id、model、prompt_version、schema_version |
| 原词与实体 | 原文词组、局部实体 ID、文中定义、对应样品/配方、semantic_role；复合配方不丢组分和配比 |
| 主张 | 主体或因素组、原始谓词、客体、方向；原始谓词始终保留 |
| 联合性 | single / jointly_reported / unresolved；因素成员、结果及证据绑定在同一 claim_id 下 |
| 科学限定 | 材料/样品身份、工况、比较对象、变化方向、必要数值单位 |
| 证据性质 | experimental / computational / theoretical / mixed / unspecified；能分开的不同支撑分别记录 |
| 断言 | reported_observation / author_explanation / hypothesis / association / design_purpose；否定与不确定措辞另存，类别允许按规则组合 |
| 来源范围 | analysis_scope、statement_origin、article_role（无法判断则未知） |
| 证据位置 | 支撑句与必要指代句的精确引用、句 ID、字符区间；各关键限定可定位 |
| 审核与问题 | accepted / revision_required / unresolved / unsupported；具体问题和修订历史 |

联合主张的最小结构示意（不是实际文献结果）：

```text
claim_id: C01
factors: [A, B]
factor_relation: jointly_reported
predicate_original: jointly contribute to
outcome: increased ionic conductivity
context: [文中报告的样品、温度及比较基准]
evidence_modality: computational
assertion: author_explanation
evidence: [原文支撑片段及位置]
```

jointly_reported 只表示作者共同归因，不自动表示各因素都是必要条件，也不等于实验证明了协同效应。图谱以主张节点关联因素和结果，或使用带共同 claim_id 的多元关系；不能把每个成员都计作独立效应。

一个主张有多个可分别验证的结果时，建立共享父主张及因素/条件的结果子项。例如 “A+B 同时提高电导率和强度”，可分别评价两个结果，但不能拆掉 A+B 的共同归因。主张完整性另行报告，避免一条复合参考关系的边界决定全部得失分。

## 5. 单篇处理流程

### A. 冻结输入与完整阅读

每篇提供完整摘要、句 ID、标题和文献 ID；标题帮助辨识语境，不能替代摘要中缺失的关系证据。初试每次处理一篇，不把多篇材料条件混在同一记录中。句子切分只是定位手段，不能切断跨句指代。

### B. 原文主张提取

先不展示旧三元组、概念合并结果和预期机制链。以完整摘要为上下文，列出范围内的主张和精确证据，再填写参与对象、联合性、条件和断言。维护逐句覆盖账本：每句可关联多条主张，或标记为背景、方法说明、单独数字、无范围内主张、歧义待定，并给短理由。

账本能定位遗漏候选，不能把“每句都有状态”称为召回率达标。明确没有范围内关系时允许空结果，不能为达到每篇数量配额生成关系。

### C. 原文优先的覆盖复核

另一个隔离旧结果的模型上下文先根据同一摘要和冻结范围形成主张清单，然后才与 B 比较。复核角色重点找：未覆盖句/从句、第二个结果、限制条件、否定、联合因素、跨句指代和计算模态。

先核实新增候选的原文支持，再合并；不同轮次的并集不自动全部接受，两个轮次相同也不自动视为真值。不能实现上下文隔离时必须记录限制，不能称为盲核查。执行可以顺序完成，不要求并行代理。

### D. 支持性复核与程序校验

模型逐项核对主体、谓词、客体、方向、共同因素、必要条件和断言强度是否被原文蕴含。程序检查引用位置、ID、必填字段、空值语义、来源哈希、成员引用、重复记录和输出完整性。化学式、电荷、单位异常只报警，不自动更正。

局部修订之后只复核被改动的主张及其关联项。初试每篇最多一轮覆盖复核和一轮针对性修订；剩余分歧保留 unresolved，并统计比例，避免无限自我修订。

### E. 定义、规范化与新旧对照

主张通过后，结合该篇定义将原词映射到域内概念。旧的已接受映射仅在实体指向与上下文相符时复用；新增/变化实体另审。iTE 与 TG 保持各自 ID，跨域匹配放到后续阶段。

输出新旧差异：保留、限定补全、补抽、重组、移入扩展集合、未支持/待定。旧结果中出现而新结果没有的主张也必须回看原文，避免重抽反而丢掉已有正确关系。

## 6. iTE/TG 专用核查规则

以下是防止误读的核查项目，不是用来从关键词自动补机制的规则。

| 易混处 | 处理要求 |
| --- | --- |
| 来源域与物理机制 | iTE/TG 只标记语料来源；每条关系按原文判定机制范围，保留混合机制及相邻电子热电研究 |
| 电导与热导 | ionic/electronic/total electrical conductivity、thermal conductivity 分开；未指明类型就保留未知 |
| 热电势与系数 | 离子、电子及热电化学语境，单元与串联器件层级，电压与系数分别记录；α/S 必须回到本篇定义 |
| 熵与热扩散量 | reaction entropy、transfer/Eastman entropy、未具体定义的 ionic entropy，以及 Soret/thermodiffusion 描述不自动视为同义 |
| 电极与体相 | 体相扩散、界面电子转移、反应动力学及离子迁移分别标注；不能仅由总性能改善反推中间机制 |
| 混合贡献 | 热电化学、电化学电势、压阻或其他共同贡献显式分组；不把输出全部归于一种机制 |
| 材料身份 | 配方、掺杂比例、离子电荷、氧化态、溶剂、凝胶网络、处理历史及几何层级中决定关系含义的部分不得丢失 |
| 比较与条件 | 保留参照材料/基线、温差位置、温度区间、浓度、湿度等已报告限定；没报告不补值 |
| 方向和结论 | 高/低、升/降、正/负号、未改善、短期改善但长期失效分别保存；不从数值正负自动推出载流子机制 |
| 目的与证据 | used to/intended to 不能无依据变成已观察增益；模拟、理论解释与实验观测分开 |

实际回归锚点包括 iTE:P0670 的共同固定阳离子因素、iTE:P0815 的制备目的、TG:P0173 的混合电势贡献、TG:P0183 的 MD 模态。它们已参与调试，不能进入新的独立验收分母。

## 7. 用对照试验选择方法

### 样本安排

1. 开发：从已检查材料中选 iTE/TG 各 20 篇，覆盖联合、计算、长摘要、跨句、否定、空结果及扩展范围。开发样本不用于总体达标声明。
2. 回归：已有约 50 条挑战案例单列，验证关键错误是否重现；不混入随机验收准确率。
3. 验收：规则冻结后，从未参与本轮规则修订及案例调试的论文中，每域分层随机抽 30 篇。按年份与摘要长度控制覆盖，记录抽样框、入选概率和排除范围；不根据预期难度或旧抽取成功与否删样本。重复/近重复论文作为同一分组，避免跨开发与验收泄漏。
4. 候补：另冻结每域 30 篇的第二波样本用于预定补充或修改后的再次验证。若第一波结果用于改提示词，它立即转为开发资料，不能继续称为独立测试。

每域 30 篇只是与现阶段规模相称的阶段性设计，不是经功效计算得出的充足样本量。历史全库归一化已接触过部分上下文，因此“未用于本轮修订”不等于模型从未见过文献，须披露。

### 参考集与公平比较

在查看待测输出之前，Astra 按冻结规则从原文建立参考集并保存哈希。明确这是模型参考集。计分阶段匿名化方法标签，避免依据“新方法”身份偏向判定。抽取中的覆盖复核属于流水线的一部分，不能直接作为独立测试参考答案。

参考答案有歧义时记录裁决依据；若新增参考关系，必须对所有比较方法一致重计。不能只为某个方法补参考，也不能偷偷更改分母。

比较三个版本：

- V0：旧抽取，按相同新范围重新评价，作为工作基线。
- V1：完整主张字段的一次抽取加相同支持性复核。
- V2：V1 加原文优先的覆盖复核，再执行相同支持性复核。

V1/V2 使用相同模型、输入、schema、规范化和计分方法；保留中间输出。它们之间的差异用于估计覆盖复核的额外贡献。V0 与新方法可能有模型/历史流程差异，其比较不能用于隔离单一组件的因果效果。开发期选择方案，冻结后再在新样本验证，不能用测试分数反复选择提示词。

### 计分单位和指标

原文支持的“一个结果 + 完整参与对象/联合因素 + 必要限定”作为可计分关系单元。参考与输出均按同一规则展开多结果，保留父主张。语义等价表述允许匹配；不要求字符串相同。重复表达只算一次正确命中；多造边仍计入输出分母。

- 严格精确率：完全得到原文支持且保留必要限定的输出单元 / 全部输出单元。unresolved 不能作为严格正确；不支持的新增关系照常计错。
- 严格召回率：被完整覆盖的参考单元 / 全部范围内参考单元。部分覆盖单列，不能直接算完整命中。
- 诊断指标：语义支持率、联合因素完整率、模态/条件遗漏率、指代错误率、重复率、整条父主张完整率、未决比例。
- 语义归一化正确性另测，不能用归一化分数替代抽取分数。
- 主机制/扩展集合、iTE/TG 分别报告；同时报告整个预定义抽取范围的结果，不事后仅展示得分高的部分。
- 报告分子分母、按论文平均及关系汇总指标。分层样本使用设计权重，区间估计以论文为聚类单位，避免把同篇多条边当独立样本。无参考主张论文的召回率记不适用，同时检查其是否产生虚假输出。
- 另报每篇耗时、输出量、修订次数及可观察的资源用量。关系数增加不是方法成功的标准。

### 扩大条件

沿用项目管理目标：两域严格精确率约 90%、核心关系召回约 70%，进入可用集合的引文定位全部通过，已发现的虚构/反向/独立化联合因果错误须处理。先按冻结计分口径报告点估计和区间；点估计达标不等于已证明总体下限达标。

如果 V2 增加无依据关系导致精确率失守，修订或取消该步骤；如果仅字段修复有效、覆盖仍低，就回到范围界定和逐句查漏。若误差集中某类型，先重做该类型；只有证据显示遗漏广泛且新方法改善稳定，才安排全库分批重读。修改规则后的再验收使用新样本，禁止通过重复抽样直到出现好成绩来宣布成功。

## 8. 提示词任务约束草案

### 提取轮

```text
输入为一篇冻结摘要及句 ID。只根据给定文本提取作者明确陈述、符合已冻结范围的主张。
完整阅读摘要，不限制关系数量；不根据领域常识补全缺失链条，不因来源域推定机制。
每条主张保存原始谓词、实体/样品身份、结果、联合因素、必要条件、证据性质及断言强度。
没有报告的内容留空并标明原因。多个因素共同归因必须绑定，多个结果共享原有约束。
引用必须精确；必要时联合引用指代句和定义句。保留否定、目的、预测和限制。
逐句列出覆盖情况；没有范围内关系可输出空清单。最后输出结构化主张和待定问题。
```

### 覆盖轮：先不提供提取结果

```text
按冻结范围从原文建立主张清单及证据位置，重点检查第二结果、联合因素、跨句指代、
负结果、比较基准、条件及计算/实验区别。不要猜测另一轮已经抽取了什么。
清单保存后才接收待比较结果；逐项标记已覆盖、部分覆盖、遗漏或范围争议。
所有新增候选必须有原文证据；没有支持不得因有利于图谱连通而补入。
```

### 支持性核查轮

```text
逐项核对主张是否被完整摘要支持，关注端点、方向、共同因素、样品、工况和断言强度。
分别标记语义错误、必要限定缺失、表示问题、歧义；给出最小必要修订及精确证据。
作者报告并不等于科学因果已确证；多个模型一致并不代替原文证据。
```
