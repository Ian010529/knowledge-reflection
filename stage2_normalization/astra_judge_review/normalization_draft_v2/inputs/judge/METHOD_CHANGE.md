# 当前验收方法：Astra 模型验收

用户已再次明确：人工抽检已用本任务 Astra 检查替代。当前归一化验收、风险抽检与后续授权审计均采用模型执行，不再以等待人工审阅作为门槛。判断记录在 judge 字段，不冒称 human_decision 或人工准确率。

本轮固定50组731成员由gpt-6-astra/high任务配置执行抽检。44组维持原分区，6组修订，修订前记录和版本一数据保留。未进入50组的其余290组沿用此前全量模型复审结果。证据不足可以由模型明确保留待定；这不自动产生人工批准要求。

程序校验只说明覆盖、溯源和映射一致性。当前验收不是独立人工基准，风险导向样本不能给出无偏总体准确率。研究计划的200条关系、60篇摘要、约50项挑战样本是不同对象的抽取审计，不能拿本轮50个归一化分组替代；后续也按已授权的Astra方式执行。
