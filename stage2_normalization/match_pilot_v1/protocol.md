# 40 篇开发试验：冻结协议

2026-09-24；用户已授权执行。运行性质为开发试验，不开放正式图谱质量门槛。

输入固定为 role_development_papers.csv 的两域各 20 篇。既有非随机、已接触样本，不作新样本验收。Astra 直接阅读完整 Abstract 作语义抽取与一轮复核；代码仅定位引文、物化数据、计算图与分数。初稿冻结后再复核，复核版冻结后才读旧边和匹配候选。未使用另一域预期对应来修改抽取。

关系粒度、范围和角色遵循 ../CROSS_DOMAIN_MATCH_EXTRACTION.md。综述概括与假说保留标签；孤立性能数值及背景不作为机制边。联合因素作为一个联合端点并保留因素列表，不拆成独立效应。语义规范名称由 Astra 随抽取明确给出，最终按域内同名同角色合并，跨域 ID 独立。没有经过语义批准的模糊合并不执行。

主图使用四类主范围；外围边另存。边权为独立 DOI（缺 DOI 用 paper_id）数。配对排除同 DOI。同义词规范化不把不同物理量、机制、样品的证据合并成单篇因果链。

本地缓存 Nomic embed-text-v1.5，revision e9b6763023c676ca8431644204f50c2b100d9aab；768 维，L2 归一化，clustering: 前缀；关系及两个端点各自编码。候选为关系整句余弦双向 Top-20 与精确通道并集。相同候选池上计算：
- Exact：两个规范端点和规范谓词全同；不足 k 项时报告实际返回量及 abstention，不用零分随机边冒充命中。
- Semantic：0.5×关系文本余弦 + 0.25×主体余弦 + 0.25×客体余弦。
- Relation-constrained：0.65×Semantic + 0.20×有向端点角色一致比例 + 0.15×规范谓词一致。
- Neighborhood：0.80×Relation-constrained + 0.20×主体/客体非当前边一跳签名 Jaccard 均值。签名包含方向、谓词、相邻角色；双方空邻域记 0，不当作正证据。

权重直接预设，不用候选标签调参。该 pilot 不构造新概念层级；条件仅原样保存并在评价时判断，不因未报告获得相似度奖励。完整条件/层级评分留待正式实验，因此本次约束版是明确简化实现。另输出去邻域、去角色/谓词的现成对照。并列用稳定哈希排序，随机种子 20260924。

四方法 Top-50 的并集打乱、隐藏方法与分数，Astra 逐对评价证据支持、关系匹配 2/1/0、条件 compatible/conflict/insufficient，附理由。2 要求具体关系可对应，1 为仅较抽象共性/对象或机制不同，0 为不匹配/相反；不能仅凭都提高热电性能判 2。严格正例为双方摘要支持且等级 2；条件不足单列，不把匹配当作可迁移性。报告 P@20/P@50、返回数、来源论文对多样性；重复论文、综述敏感性。

同一 Astra 会话先抽取后评价，仅做隐藏排序信息，不能宣称独立盲评或外部金标准。旧抽取比较为同 40 篇事后对照；未另建独立参考集时不报告新方法真实 precision/recall。初稿与复核差异报告修改类型和数量，不人为制造提升。保存输入/版本哈希和运行清单。
