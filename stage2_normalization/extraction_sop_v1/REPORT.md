# 12 篇抽取 SOP 实验结果

2026-09-24。**实验已完成。一次集中复核修正了实际错误并补回遗漏，值得保留；本轮没有证明总体抽取达到 90%，也没有证明全量重抽或跨域匹配会改善。**

本轮只执行抽取、一次查漏纠错、模型参考对照与技术校验。Astra 本会话直接作语义判断，Python 仅物化记录与计数；没有调用付费 API、启动旧任务、运行建图/匹配或修改源语料。所用 SOP 是 SciERC 规则组织方式和 ChatExtract 简单抽取/核验思路的领域适配，不是对两个原方法的完整复现或性能复现。

## 3. 定位到的抽取问题

| 类型 | 例子 | 一次复核的处理 |
|---|---|---|
| 并列因素被写成共同归因 | P0429 碱液用量、温度、离子运动 | 改为列举的三种影响；不补效应方向或独立贡献量 |
| 设计目的被写成已观察效果 | P0169 `is designed to`、`provided ... to increase` | 保留目的性/假说状态 |
| 中间因果节点归属过强 | P0169 面积→反应位点/界面阻力 | 保留整体电极设计归因，不强造面积介导链 |
| 范围/极值被改写成单调规律 | P1791 带隙范围；P0322 最低电位处效应最大 | 保留范围关联/极值，不声称全区间单调 |
| 模糊符号被强行物理解释 | P1791 `kappa/z` | 保留原记号，物理量身份待定；不按常识修复 |
| 直接关系藏进复合节点 | P0083 改性电极属性与配位参与者；P0257 离子相互作用参与者 | 补回 4 条独立直接边，仍保留已有作用关系 |

这说明问题不仅是漏句，还包括**把原文表达改得过强，以及把关系压进节点标签**。增加关系数量本身不能解决这两类问题。

## 4. 探索性数值：只表示本会话模型判定

严格接受率 = 被本次模型接受的记录 / 输出记录。参考覆盖率 = 完整覆盖的明确参考关系 / 明确参考关系。必要限定缺失不算完整覆盖；一个旧复合结果可覆盖多个明确原子结果，但把关系仅藏在节点名中不算保留直接边。全部映射可查，不用字符串相似度代替语义判断。

| 集合 | 首轮严格接受 | 复核后严格接受 | 首轮参考覆盖 | 复核后参考覆盖 |
|---|---:|---:|---:|---:|
| iTE，6 篇 | 30/33 = 90.9% | 34/35 = 97.1% | 30/36 = 83.3% | 34/36 = 94.4% |
| TG，6 篇 | 19/24 = 79.2% | 28/28 = 100% | 19/28 = 67.9% | 28/28 = 100% |
| 本次合并样本 | 49/57 = 86.0% | 62/63 = 98.4% | 49/64 = 76.6% | 62/64 = 96.9% |

主范围（排除两个外围关系）的对应合并数为：47/55→60/61，参考覆盖47/62→60/62。按 TG 独有/交集拆分及全部分子分母见 [metrics.csv](metrics.csv)。不将分层样本的合并比例外推为语料总体比例，也不计算缺乏独立裁判支撑的显著性结论。

一个原文物理量身份待定项不放入“明确参考”分母，但仍放入输出分母并不算严格接受。如果将它也保守放入参考分母且按未完整覆盖处理，复核后为62/65=95.4%，而不是悄悄删除难例后声称达标。

**98.4% 是本轮同会话判定下的修订后接受率，不是已独立验证的新方案精确率。** 修订与评价共享判断尺度，会偏乐观；新样本与独立判定是两件事。本轮也未执行计划规定的每域100条/30篇正式验收，因此正式质量门槛仍未通过。

## 5. 旧结果对照与残留问题

在参考冻结后读取同12篇的17条旧 focal-claim 记录。旧记录在当前参考下完整覆盖14/64条；这些14条在复核稿中全部保留。一个旧结果同时明确包含滑动与分离，公平映射到两个参考关系，没有因为旧记录条数少而只计一次。

该比较表示“选择性核心陈述”与“范围内全部明确关系”的覆盖差距。两者抽取目标不同，不能将14/64直接称为旧模型失败率或声称新模型能力提升了若干倍。引用上下文可用于解释旧记录；没有对缺失旧字段做统一错误惩罚，也未计算旧生产系统精确率。见 [逐条旧结果判定](baseline_judgments.json)。

复核冻结后原文核对仍发现：

1. P1860：C2/m体系中p-d耦合被禁阻，仍只留在另一条边的主体里，没有独立保留材料/结构的否定属性关系。
2. P1604：[C4mim]Cl用于Bi2Te3剥离的直接方法—过程关系未单列；“稳定分散”不能替代它。
3. P1791：`kappa/z` 物理量身份待定，需要可靠原文才能解决；本轮没有查全文或补猜。

这些问题没有反改已冻结复核稿，避免评估后再修到满分。它们说明一次复核有价值，但仍会漏掉已知类别的问题。

## 6. 语料与研究目标的边界

随机样本中 P1860/P1791 为电子结构/电子热电计算，P1948 为硒化物结构及光磁性质，P0322 是腐蚀而不是热电化学发电，P1604 是材料剥离机制。P0716 的超离子材料也不能直接等同于典型离子热扩散器件。来源集合不能代替物理机制分类。

按既定语料政策，这些论文没有被删除；已述关系仍按统一范围抽取。但其“抽取得正确”不证明它们适合目标跨域match。现在先解决抽取问题，这个观察只作为语料诊断，不扩展为新筛选系统或调整匹配算法。
