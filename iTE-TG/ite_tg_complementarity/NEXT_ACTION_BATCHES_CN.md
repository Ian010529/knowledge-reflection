# 下一步实验批次：不要把 15 条各做成一只器件

总原则：每个共享平台都按“溶液/界面证伪 → 材料 coupon → 只有 survivor 做器件”。同批次复用电解液、电极、恒温夹具和表征流程。

> 默认内部筛选线（可按实验噪声调整，并非文献声称）：机制信号超过max(3σ, 基线20%)；关键扩散/电导保留至少50%，Rct不超过基线2倍；反转ΔT须可逆且ΔT=0无伪电势；器件阶段计入泵送/主动切换后净功率至少提高20%。

## B1. ferri/ferrocyanide 共用平台

**成本级别**：低到中

**共用平台**：同一批 K3/K4[Fe(CN)6]、同电极面积/间距与恒温夹具；先共用温变 UV–vis/CV/EIS/扩散，再按需加入流场或再生回路。

**顺序逻辑**：先做 Manning 与 Donnan 小样，再做取向/EHD coupon；只有前述传质与界面门控成立，才做 osmotic-regeneration H-cell 和被动 thermoosmotic loop。

**批次筛选线**：差异分配/界面效应超过 max(3σ, 基线20%)；红氧扩散/电导保留≥50%，Rct≤2倍；EHD 分区经浸泡与热循环仍存在；loop 压力平衡后仍有被动净流；无再生路径的膜体系只能标为热充电–放电；净功率增益不足20%即停止。

### 1. 测试多阳离子链的 Manning 凝聚能否区分 3−/4− 红氧阴离子

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先测 [Fe(CN)6]3− 与 [Fe(CN)6]4− 在多阳离子网络中的 K3(T)、K4(T) 和扩散，不先做完整器件。
- 继续/停止：只有 K3/K4 的温度导数显著不同、过程可逆且两物种仍可扩散，才继续。
- 来源/基线：P0344 → P0018

### 2. 在 TG 电极前构建 Donnan 界面层，调节 3−/4− 局部活度与动力学

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先测 3−/4− 在界面层中的分配比随温度是否变化，并同时测交换电流/EIS。
- 继续/停止：若分配差无温度导数，则只作为电极动力学改进，不宣称放大 dE/dT。
- 来源/基线：P0400 → P0041

### 3. 用取向离子通道解耦 TG 凝胶的机械强度与红氧扩散

- 进入阶段：`S2_material_coupon`
- 第一步：先同时测 3−/4− 纵横向扩散、传质阻抗与纵横向模量，确认各向异性不是只对支持盐有效。
- 继续/停止：只有红氧扩散和疲劳寿命同时优于同模量各向同性对照，才算有效升级。
- 来源/基线：P0355 → P0016

### 4. 把 EHD 离子均匀化工艺扩展为 TG 凝胶的空间分区打印

- 进入阶段：`S2_material_coupon`
- 第一步：先验证 multi-ink EHD 形成的电荷/孔隙分区在灌液和平衡后仍然存在。
- 继续/停止：若分区在灌液后快速松弛，则不把短时电压当持续 TG 改进。
- 来源/基线：P0344 → P0021

### 5. 把温差诱导的渗透浓度势与 TG 红氧电势串联，而非只做单一机制

- 进入阶段：`S2_component_or_membrane_cell`
- 第一步：先比较有无再生回路的开路衰减与负载持续时间，区分一次性热充电和连续发电。
- 继续/停止：无再生回路只能标为瞬态热充电；闭路稳定输出后才标为 TG 升级。
- 来源/基线：P0360 → P0021

### 6. 在薄层 TG 中加入取向滑移纳米通道，提高短路电流而非只追求电压

- 进入阶段：`S2_component_or_flow_loop`
- 第一步：先在不对称双支路透明回路中直接测持续环流、压差和 3−/4− 通量，并交换两支路表面化学以排除自然对流。
- 继续/停止：只有不对称支路产生可逆稳态环流且能降低红氧传质阻抗，才装入 TG。
- 来源/基线：P1053 → P0018

## B2. I−/I3− 与 Q/HQ 恒温光谱–电化学平台

**成本级别**：中

**共用平台**：共用恒温 UV–vis/Raman、原位 pH、扩散池、CV/EIS 与同尺寸 TG 夹具；I3− 和 Q/HQ 分开配液但共用测量流程。

**顺序逻辑**：I3− 先做 fixed-charge × hydrophobic-recognition 2×2；Q/HQ 先做zwitterion-pH × aligned proton-channel 2×2；最后才外串联 P0373 式 Soret 子单元。

**批次筛选线**：I3− 需有可逆且有益的 dlnKpartition/dT，同时保留自由物种、扩散和交换电流；Q/HQ 必须在无外加pH差时形成可逆ΔpH，且缓冲后新增效应消失；串联总压须在±10%内等于两个独立单元的电压代数和；计入内阻/切换代价后净功率不增即停止。

### 1. 把固定正电荷通道与分子识别结合，做 I−/I3− TG 选择性隔层

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先用扩散池比较固定电荷-only、分子识别-only 和组合膜的 I3−/I− 分配与跨膜通量。
- 继续/停止：组合膜必须比两个单机制对照更能抑制 I3− 穿梭，同时不显著恶化极限电流。
- 来源/基线：P0528 → P0008

### 2. 用可调疏水微区选择性分配 I3−，同时兼顾 TG 凝胶韧性

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先测 I3− 在亲水相/疏水微区之间的 Kpartition(T) 和热循环可逆性。
- 继续/停止：若 Kpartition 对温度不敏感或热循环滞后明显，则否决分配机制。
- 来源/基线：P0336 → P0008

### 3. 用 pH 响应两性离子凝胶放大并可逆切换 Q/HQ TG 极性

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先测两性离子侧链的 pKa(T) 与冷热端原位 pH；没有自发 ΔpH 就停止。
- 继续/停止：若 dpKa/dT 太小或强缓冲后效应不消失，则否决该因果链。
- 来源/基线：P0677 → P0034

### 4. 把水热扩散驱动的质子定向输运叠加到 Q/HQ 热电化学反应

- 进入阶段：`S2_material_coupon`
- 第一步：先在无 Q/HQ 与强缓冲两种条件下测水含量/pH 空间剖面，分离质子梯度与本征红氧热电势。
- 继续/停止：反转温差时 pH 梯度须可逆，且缓冲后新增电压应同步消失。
- 来源/基线：P0392 → P0034

### 5. 用可切换 Soret 单元为 I−/I3− TG 构建等效 p/n 腿

- 进入阶段：`S3_hybrid_device_only_after_gate`
- 第一步：先用 P0373 式电极切换分别测 Soret 子单元的正/负热电压，再与 I−/I3− TG 串联并验证总压代数和。
- 继续/停止：只有两个子单元可独立读出且串联满足电压代数和，才称为混合 TG。
- 来源/基线：P0373 → P0093

## B3. Fe/Cu/Co 变温配位与溶剂平台

**成本级别**：中到高

**共用平台**：共用小体积变温配位/溶剂矩阵、UV–vis/Raman、CV/EIS、扩散和 DSC；所有体系先查物种变化，再制备聚合物或 organogel。

**顺序逻辑**：先筛 Fe 支持阴离子、Cu 配体与 Co 溶剂；只有 speciation、扩散和热响应同时过关，才做 isolated mixed-conductor、polymer-ligand 或 organogel cell。

**批次筛选线**：Fe 必须能分离支持离子热扩散与配位变化；mixed conductor 跨电解质漏电低于工作电流1%且优于等面积普通多孔电极；Cu扩散保留≥50%且沉积/剥离可逆；Co低温扩散保留室温值约30%、无不可逆配体交换且挥发损失≤5%。

### 1. 用阴离子缠结调节 Fe2+/Fe3+ TG 的支持离子热扩散项

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先在无红氧反应的支持盐凝胶中测两种阴离子的 Soret 系数/迁移数，再加入 Fe2+/Fe3+ 检查配位光谱是否改变。
- 继续/停止：只有辅助热电势可重复且 Fe 配位基本不变，才进入 TG 功率测试。
- 来源/基线：P1143 → P0002

### 2. 用聚合物配位强度调节 Cu/Cu2+ TG 的溶剂化熵与扩散

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先做均匀配体密度系列，测 Cu2+ 结合常数随温度、扩散和 ΔT=0 偏置。
- 继续/停止：只保留能改变 dE/dT、不过度降低 Cu2+ 扩散且无等温偏置的配体窗口。
- 来源/基线：P0336 → P0022

### 3. 把 iTE 低凝固混合溶剂迁移到 Co 配合物准固态 TG

- 进入阶段：`S1_solution_or_interface_gate`
- 第一步：先做溶剂小矩阵，测 DSC、黏度/Co 扩散与温变配位光谱，筛掉会改变 Co 配位反应的配方。
- 继续/停止：只有低温不冻结、Co 配位可逆且扩散仍可接受的配方才进入器件。
- 来源/基线：P0349 → P0291

### 4. 用 iTE 离子–电子耦合启发 Fe2+/Fe3+ TG 的局部混合导体电极

- 进入阶段：`S2_material_coupon`
- 第一步：先做两块彼此绝缘的局部 mixed-conducting 电极，和等电化学面积的电子绝缘孔隙电极比较 EIS，同时测漏电与自放电。
- 继续/停止：界面阻抗须在等电化学面积对照下仍下降，同时无电子贯通和额外自放电；否则只能归因于面积效应。
- 来源/基线：P0353 → P0014

## 使用方式

三个 batch 可以并行，但同一 batch 内严格按编号推进。前一阶段失败时，保留负结果和失败模式，不再投入完整器件。详细变量与原句证据分别见 `ite_tg_next_action_queue.csv` 和 `ite_tg_candidate_evidence.csv`。
