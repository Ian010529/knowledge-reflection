这些数量是节点对数量，不是最终概念数量。不能从 437 组同义建议推算“可减少 437 个节点”，也不能沿同义链自动传播到其他出现位置。

几个可直接检查的例子：

- **N0731**：同一摘要明确给出 `thermodiffusion (Soret) effect`，与 `Soret effect` 建议同义。
- **N0732**：`thermodiffusion` 比 `anion thermodiffusion` 更宽，保留阴离子限定。
- **N0736**：全文摘要明确区分 TDIEM 与 Soret 型热扩散，并讨论二者竞争，判为不同机理。
- **N0738**：摘要支持 `thermoelectric power` 在此指 thermopower；但另一节点的响应包含协同贡献，保留语境差异，未直接折叠。
- **N0726**：`ion entropy difference` 缺少足以与氧化还原反应熵变等同的定义，保持 uncertain。
- **N1018**：`electrical resistance` 与 `electrical resistivity` 分别为电阻与电阻率，明确区分。
- **N1011**：左侧虽写 `output power`，但原文单位为 μW/cm²；结合热电池语境，提出与右侧面积功率密度同义的建议，原名和原单位仍保留。
- **N0911**：电子电导率与电子热导率不同，不能按共同的 electronic 折叠。

本次修订记录保存在 `model_decisions.json` 的 `revisions` 中，含原判断、新判断及理由。N0588、N0647、N0692、N0716、N0717 撤回同义，保留热导率的程度、边界或变化差异；N0897 根据原文明确的离子热扩散场来源，从宽窄关系改为同义。首批同义数因此由 353 调整为 348，加上第二批 89 组，累计为 437。修订没有修改源节点或原文。

各批 ID 范围与选取方式固定在 [batch_plan.json](batch_plan.json)：

1. 214 个含多个可用节点的同名检索组，共 778 个出现位置，选定参考节点逐一比较，共 564 组。不是组内所有两两组合。

4. 第二批选取尚未触及且 0.7 ≤ 字符 n-gram cosine < 0.8 的全部 434 个可用单元对，各核查一对具体出现位置。不推广到单元内其他成员。阈值仅用于安排复核顺序，不代表准确率或语义置信度。

旧候选表共有 18,884 个检索单元对。其中 1,174 个因至少一侧没有角色明确的节点而暂缓，17,710 个至少有一对可比较节点。累计触及其中 601 个单元对，另有 **17,109 个可用单元对尚未比较任何出现位置**。即使一个单元对已触及，也不能把一对节点的结论推广到整个单元。另有 3,142 个可用节点未出现在累计比较中，部分节点未必需要同义比较。

下一批可处理剩余 0.6 ≤ cosine < 0.7 候选，并补查已经触及的检索组内未覆盖语境。274 组归一化疑义与原有 161 项角色疑义是不同对象、不同计数单位；分别保留，均不阻塞其他明确项的比较。它们可按是否影响后续机制链分析排序，不能为了提高归一化比例强制给出同义结论。
