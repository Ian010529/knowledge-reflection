## 为什么还有 159 项

| 当前问题 | 项数 | 处理边界 |
| --- | ---: | --- |
| 现有十类不覆盖器件、方法、模型等对象 | 51 | 保留类别缺口，不将它们硬塞进材料或物理过程。 |
| 同一节点混合多个角色 | 48 | 保留完整节点，不静默拆分或挑选其中一部分。 |
| 定义、对象或角色边界不足 | 58 | 保留暂定角色或留空及具体原因，不凭常识补物理定义。 |
| 来源措辞或单位需核对 | 2 | 保留原始 modules、mW m(-1) 等写法，不擅自纠正。 |

这些不确定项已经过本轮证据复核，不能再把它们当作未读任务反复消耗模型。类别缺口、复合表示及缺少原文定义需要不同的后续处理；本轮不扩大任务到改本体、拆节点或查论文全文。

## 复现

在项目根目录执行，输出目录必须尚不存在：

```bash
python3 stage2_review/scripts/materialize_roles_v2.py --output /tmp/ite_tg_role_review_v3 --review-decisions stage2_review/role_review_v2.json --followup-decisions stage2_review/role_review_v3.json
```

脚本只连接、保存及校验已记录的模型判断，不按关键词推断角色。旧第二轮 343 项疑义复核与研究方案中缺失的 343 项既有合并决定是不同清单，不可混用。
